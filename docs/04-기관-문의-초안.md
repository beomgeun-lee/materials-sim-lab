## 1. NOAA — CAMEO Chemicals 반응성 데이터 (영문)

**Subject:** Reuse terms and machine-readable access for CAMEO Chemicals reactivity data

Dear CAMEO Chemicals team,

I am developing an open-source research and education tool that simulates what happens when
elements, minerals and chemicals are combined. Before any simulation runs, the tool shows a
**mixing-hazard warning**. We would like to base that warning on the CAMEO Chemicals reactive-group
methodology and credit it clearly.

Could you help with the following questions?

1. **Reuse terms.** Are the reactive-group assignments, the pairwise reactivity predictions
   (the RGx–RGy documentation pages) and the reactivity profiles in the public domain?
   If not, under what terms may we store them and redistribute them in an open-source tool?
   We understand that third-party data in CAMEO Chemicals (e.g. NFPA, AEGL, ERPG, CAS) is excluded.
2. **Machine-readable access.** Is the reactive-group × reactive-group compatibility matrix
   (hazard codes, gases generated, references) available as a download or a data file,
   for example the one that ships with the desktop application? Your robots.txt disallows crawling
   `/reactivity`, so we will not scrape it.
3. **Attribution.** How would you like CAMEO Chemicals to be cited in the tool and its documentation?
4. **CRW 4.** Does the Chemical Reactivity Worksheet (now distributed by AIChE CCPS) use the same
   rule set, and should we contact CCPS about reuse separately?

The warnings will only be used to prevent hazardous mixing. The tool does not give synthesis or
manufacturing procedures.

Thank you for your time.

Project: materials-sim-lab (open source, Apache-2.0, not yet published)

## 2. 한국산업안전보건공단 — 물질안전보건자료(MSDS) 조회 서비스

**제목:** 물질안전보건자료 조회 서비스(공공데이터포털 15157612) 데이터 이용 범위 문의

안녕하십니까. 원소·광물·화학물질을 조합했을 때의 결과를 시뮬레이션하는 연구·교육용 소프트웨어를
개발하고 있습니다. 이 소프트웨어는 혼합 위험 경고와 국내 규제 정보를 보여 주는 데 귀 기관의
MSDS 조회 서비스를 활용하려 합니다. 이용 범위를 확인하고자 문의드립니다.

1. 공공데이터포털에는 이용허락범위가 '제한 없음'으로 표시되어 있습니다. 그런데 공단 누리집에는
   MSDS를 상업적으로 이용하면 저작권 위배가 될 수 있다는 안내가 있습니다. 두 안내 가운데 어느 쪽을
   따라야 하는지 알려 주십시오.
2. API로 받은 항목 가운데 9번(물리·화학적 특성)과 10번(안정성 및 반응성)을 데이터베이스에
   저장하고 가공(표준화·다른 데이터와 연결)해도 되는지 알려 주십시오.
3. 가공한 결과를 오픈소스 소프트웨어의 데이터로 함께 배포해도 되는지, 된다면 출처를 어떻게
   표시해야 하는지 알려 주십시오.
4. 향후 유료·상업 서비스에 포함하려면 별도 승인 절차가 필요한지 알려 주십시오.

회신 주시면 그 조건에 맞춰 이용하겠습니다. 감사합니다.

## 3. 국가소재연구데이터센터 — 소재 데이터 이용 조건

**제목:** 소재 연구데이터 이용 조건 및 API 제공 여부 문의

안녕하십니까. 공공 소재 데이터를 바탕으로 소재 조합을 가상으로 시험하는 오픈소스 연구·교육용
프레임워크를 개발하고 있습니다. 귀 센터의 데이터를 연계하고자 다음을 문의드립니다.

1. 데이터 라이선스(공공누리 유형, CC 등)가 데이터셋마다 다른지, 일괄 조건이 있는지 알려 주십시오.
2. 프로그램으로 조회할 수 있는 API가 있는지, 있다면 신청 절차와 호출 한도를 알려 주십시오.
3. 데이터를 내려받아 자체 DB에 저장하고 가공해도 되는지, 해외에서 개발하는 오픈소스
   협업자와 공유할 때 제한이 있는지 알려 주십시오.
4. 현재 공개된 데이터 규모를 알려 주십시오. 누리집에 107만 건, 199만 건 등 서로 다른 수치가
   보입니다.
5. 소재 데이터 스키마(Materials System)와 표준어휘집 최신판을 참조용으로 받을 수 있는지
   알려 주십시오.

감사합니다.

## 4. 한국표준과학연구원 국가참조표준센터 — 참조표준 데이터 이용 협약

**제목:** 국가참조표준 데이터를 시뮬레이션 검증 기준으로 활용하기 위한 이용 조건 문의

안녕하십니까. 소재 조합 시뮬레이션 결과가 얼마나 정확한지 검증하는 기준 데이터로 국가참조표준
물성 데이터를 쓰고자 합니다. 누리집 이용약관에 사전 허가 없는 저장·배포를 금지한다는 조항이 있어
다음을 문의드립니다.

1. 참조표준 데이터를 내부 검증용 DB에 저장하려면 어떤 이용 협약 절차를 밟아야 하는지 알려 주십시오.
2. 검증 결과(예: 시뮬레이션 값과 참조값의 오차 통계)만 공개하고 원자료는 공개하지 않는 방식이
   가능한지 알려 주십시오.
3. 오픈 API가 제공하는 범위가 메타데이터뿐인지, 물성 값 본문도 받을 수 있는지 알려 주십시오.
4. 대상 분야는 열역학 물성과 상평형 관련 참조표준입니다. 해당 분야의 현재 등록 건수를
   알려 주십시오.

감사합니다.
