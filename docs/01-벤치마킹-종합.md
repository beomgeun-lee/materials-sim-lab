## 결론

1. **'조합 하나 → 여러 종류의 시험'을 한 흐름으로 제공하는 제품은 없다.**
   도구가 도메인별로 끊겨 있다.

   | 도메인 | 대표 도구 | 입력 표현 |
   |---|---|---|
   | 무기 결정 | MP, OQMD | CIF |
   | 분자 | PubChem, RDKit | SMILES |
   | 수용액 | PHREEQC | 용존종 |
   | 합금 | CALPHAD | 몰분율 |
   | 혼합위험 | CAMEO | CAS |

   입력 표현이 서로 달라 도구를 이어 주는 계층이 없다. **그 연결 계층이 우리가 만들 것이다.**

2. **계산 엔진은 새로 만들 필요가 없다.**
   도메인마다 성숙한 오픈 엔진이 있다. 예를 들면 pymatgen, PHREEQC·Reaktoro, Cantera, pycalphad, 범용 머신러닝 원자간 포텐셜(uMLIP)이다.
   차별점은 엔진이 아니라 다음 네 가지다.
   - 공통 조합 레시피 스키마
   - 도메인 라우터
   - 안전 게이트
   - 프로비넌스(출처·계산 이력 추적)

3. **데이터 골격은 재배포 가능한 공공데이터만으로 만들 수 있다. 가장 큰 리스크는 라이선스다.**

   | 제약 | 소스 |
   |---|---|
   | 비상업 전용 | GNoME, AFLOW, Mindat, CAS Common Chemistry |
   | 재배포 허가 필요 | NIST SRD, ICSD, KOMIS, KRISS 참조표준 |

   따라서 레코드 단위로 출처와 라이선스를 추적해야 한다.

4. **서로 다른 계산 DB의 에너지는 섞을 수 없다.**
   - 범함수(PBE, r²SCAN, OptB88vdW)와 보정 체계(MP2020, OQMD)가 다르다.
   - 계산값과 실험값의 차이도 크다. 형성에너지 MAE가 51~96 meV/atom이고, PBE 밴드갭은 약 40% 과소평가된다.
   - 그래서 모든 결과에 에너지 기준과 충실도 태그가 필요하다.

5. **시뮬레이션은 '깔때기 + 평형 트랙' 두 축으로 짠다.**
   - **평형 트랙**: 열역학 DB가 있는 영역(수용액·기체·평가된 합금)에서는 평형 솔버가 노트북에서 1초 안팎에 검증된 답을 낸다.
   - **깔때기**: DB에 없는 신규 조성은 L0 규칙 → L1 ML → L2 uMLIP → L3 DFT 순으로 좁힌다.
   - 신규 무기 화합물의 안정성 판정은 uMLIP(F1 0.90~0.93)가 주력이다. 조성만 쓰는 ML(F1 0.33~0.57)은 필터 용도로만 쓴다.

6. **가장 큰 공백은 안전이다.**
   - 혼합위험 판정은 사실상 CAMEO 반응성 그룹 체계 하나뿐인데, 시뮬레이션 흐름 밖에 따로 있다.
   - 2026-07 에이전트 안전 벤치마크에서 화학·소재 에이전트는 실행의 25.6%에서 위험 절차를 노출했다.
   - 대응: 모든 시험 앞에 안전 게이트를 기본으로 둔다.

7. **2026년 시장은 폐쇄형 기업용 제품으로 몰렸다.**
   - 예: Matlantis의 Claude Code 내장, Microsoft Discovery 정식 출시(GA), CuspAI·Periodic Labs 대형 투자
   - 오픈·자체 호스팅·공공데이터·교육 영역은 비어 있다.

8. **포지셔닝 권고**
   - 코어는 오픈 SDK와 MCP로 만든다.
   - 첫 화면은 교육용 가상 조합 실험실로 한다.
   - 산업용 스크리닝은 앞의 둘을 검증한 뒤 진행한다.

## 조사 신뢰도

- 세 조사는 에이전트가 2026-09-26에 웹 페이지, PyPI, GitHub, 각 API를 직접 조회해 수행했다.
  - 각 문서 끝에 출처 URL과 미확인 목록이 있다(데이터 27건, 엔진 16건, 플랫폼 21건).
  - PyPI 버전과 리더보드 수치는 조회 시점 값이다. 리더보드 상위 10개 중 8개가 2026년에 새로 등록됐을 만큼 변화가 빠르다.
- 라이선스 판단은 공개 문서를 해석한 것이며 법률 자문이 아니다. 상업화 전에는 법무 검토가 필요하다.
- 투자액과 제품 출시 같은 시장 동향은 보도자료와 기사에 근거한다. 1차 검증 수준이 기술 사실보다 낮다.
- 계획에 직접 영향을 주는 미확인 항목은 [계획서 10절 선행 확인](02-계획서.md)으로 옮겼다.
