# 01. 공공·오픈 소재 데이터 소스 조사

- 기준일: 2026-09-26 (웹·API 실측 기준, 확인 못 한 항목은 "미확인")
- 범위: DB 원천이 될 데이터 소스. 시뮬레이션 엔진과 통합 플랫폼은 다른 문서에서 다룸
- 표기
  - `[E1]` 형식은 문서 끝 출처 목록 번호입니다.
  - "실측"은 2026-09-26에 API나 파일을 직접 조회한 값입니다.
  - "스니펫"은 원문 접근이 막혀 검색 요약에만 근거한 값입니다.
- 라이선스 판단은 공개 문서를 해석한 것이며 법률 자문이 아닙니다. 상업화 전에 법무 검토가 필요합니다.

## 0. 요약

### 0.1 핵심 결론

1. **재배포 가능한 골격은 공개 데이터만으로 만들 수 있습니다.**
   - 원소: mendeleev + CIAAW 2024
   - 구조: COD(CC0), Materials Project(CC BY 4.0)
   - 분자: PubChem
   - 기상·응축상 열역학: NASA CEA thermo.inp(Apache-2.0)
   - 수계 열역학: PHREEQC 동봉 DB(USGS)
   - 광물명: IMA 목록(CC BY-SA 3.0)
   - 수급: USGS MCS(CC0)
2. **최대 리스크는 라이선스입니다.**
   - 비상업(NC) 전용: GNoME, AFLOW, Mindat, C2DB, CAS Common Chemistry
   - 재배포에 허가 필요: NIST SRD 전반(JANAF, WebBook, ASD)과 국내 KOMIS, 국가참조표준
   - 따라서 **레코드 단위로 `source`, `license`, `version` 필드를 두는 것이 필수**입니다.
3. **DFT DB끼리 총에너지를 섞을 수 없습니다.**
   - 범함수가 다릅니다: PBE(+U), r²SCAN, PBEsol, OptB88vdW.
   - 보정 스킴도 다릅니다: MP2020, OQMD 피팅 μ, OMat24 전용.
   - MP 안에서도 같은 물질의 형성에너지가 thermo 타입에 따라 0.2 eV/atom 넘게 차이 납니다.
4. **계산값과 실험값의 오차가 큽니다.**
   - 형성에너지 MAE: MP2020 51 meV/atom, OQMD 96 meV/atom
   - PBE 밴드갭은 약 40% 과소평가됩니다.
   - 따라서 실험·참조값 레이어(COD, NIST, KRISS SRD)를 분리해 검증에 씁니다.
5. **조합 안전성 판정은 NOAA CAMEO가 사실상 유일한 공개 규칙 체계입니다.**
   - 반응성 그룹 68개와 쌍별 호환성 규칙으로 구성됩니다.
   - 공식 벌크 제공이 없고, robots.txt가 `/reactivity` 수집을 막습니다.
   - 화합물↔그룹 매핑은 PubChem PUG-View로 받을 수 있습니다(약 5,093건).
   - 쌍별 매트릭스는 NOAA에 문의해야 합니다.
6. **OPTIMADE는 구조 검색 공통창구로만 쓰는 편이 맞습니다.**
   - 최신 스펙은 v1.3.0이고, 제공자는 28곳입니다.
   - 한계: 물성 필드가 표준화되지 않았고, 가용성이 제공자마다 다릅니다(OQMD, Alexandria-PBE는 실측 시 5xx). MP OPTIMADE는 2023년 데이터에 멈춰 있습니다.
   - 벌크 적재는 각 소스의 네이티브 경로(S3, dump, rsync)로 합니다.
7. **한국 데이터 중 즉시 쓸 수 있는 것**
   - data.go.kr: 한국환경공단 화학물질 정보·GHS API, 한국산업안전보건공단(KOSHA) MSDS API(20,568종), 한국광해광업공단 CSV
   - 이 중 KOSHA MSDS는 포털 표기(이용허락범위 제한 없음)와 KOSHA 사이트 문구(상업 이용 위배 가능)가 상충합니다.
   - KOMIS와 국가참조표준은 복제·재배포 금지 조항이 있어 허가 전 적재가 불가합니다.
   - 국가소재연구데이터센터(K-MDS)는 규모가 크지만 라이선스와 API가 미확인입니다.

### 2.11 DB 간 혼용 시 주의점
1. **범함수와 계산 설정이 다르면 총에너지를 섞을 수 없습니다.**
   - PBE(+U): MP, OQMD, AFLOW, Alexandria, OMat24
   - r²SCAN: MP 일부, MatPES
   - PBEsol: Alexandria, MC3D
   - OptB88vdW: JARVIS
   - 따라서 hull은 소스별로 따로 계산합니다.
2. **보정 스킴이 서로 호환되지 않습니다**: MP2020, OQMD 피팅 μ, OMat24 전용 보정.
3. **라이선스가 파생물로 전파됩니다.**
   - NC(GNoME, AFLOW, C2DB)나 SA(CMR)가 섞이면 파생 DB 전체의 상업 이용이 막힐 수 있습니다.
   - 따라서 레코드 단위로 출처를 추적합니다.
4. **중복이 많습니다.** ICSD 유래 구조가 여러 DB에 겹쳐 있으므로 `StructureMatcher`로 중복을 제거하고 출처를 보존합니다.
5. **계산값과 실험값의 오차**
   - 형성에너지 MAE는 약 50–100 meV/atom이고, 실험값끼리도 82 meV/atom 차이가 납니다.
   - PBE 갭은 과소평가됩니다.
   - ML 평가 시 WBM 등 벤치마크 데이터가 학습셋에 섞였는지 점검합니다.

### 5.2 NOAA CAMEO Chemicals — 우선순위 상(조합 안전성)

## 10. 한국 공공데이터 활용 방안

1. **국내 규제·안전 기준 테이블(즉시)**
   - 한국환경공단 화학물질 정보 API로 `CAS ↔ KE번호 ↔ 분자식 ↔ 규제분류` 마스터를 만듭니다.
   - 여기에 유독물 GHS API와 KOSHA MSDS(9번 물리화학, 10번 안정성·반응성)를 붙입니다.
   - PubChem CID와 CAMEO 반응성 그룹을 CAS로 조인하면 **국내 규제와 반응성을 함께 판정하는 조합 안전성 레이어**가 됩니다.
2. **광물 원료 경제성 파라미터(즉시)**
   - 한국광해광업공단 CSV(매장량, 교역, 용도, 가격예측, 수급지수)와 USGS MCS, Pink Sheet를 결합해 광종별 비용과 공급 리스크 계수를 만듭니다.
   - KOMIS 원가격은 쓰지 않습니다.
3. **국내 광물·지구화학 데이터(2차)**
   - KIGAM 지오빅데이터와 DataON에서 **CC0/CC BY 데이터셋만** API로 필터링해 수집합니다.
   - 라이선스 필드(`dataset_cc_license_pc` 등)를 저장합니다.
4. **검증 벤치마크(협약 후)**
   - KRISS 국가참조표준 물성을 이용협약 후 시뮬레이션 검증 기준으로 씁니다.
   - 협약 전에는 DOI와 메타데이터만 연계합니다.
5. **스키마 정합**
   - K-MDS의 "Materials System" 스키마와 표준어휘집(9판)을 내부 스키마 설계에 참조합니다.
   - 이렇게 해 두면 이후 K-MDS, KoMaP, AI Hub 합금 데이터를 연계하기 쉽습니다.
6. **선행 확인 요청(공문·문의)**
   - KOSHA: MSDS 상업 이용 조건
   - K-MDS: 라이선스와 API
   - KRISS: 참조표준 DB 적재 협약
   - AI Hub: 상업 이용과 해외 반출 조건

## 12. 미확인·추가 확인 필요 항목

### 라이선스(적재 결정에 직접 영향)
1. **CAMEO**
   - 반응성 데이터의 퍼블릭 도메인 여부
   - 쌍별 호환성 매트릭스의 공식 제공 여부(NOAA 문의)
   - 데스크톱판 내부 DB 형식
   - CRW 4.x의 현행 AIChE 이용조건
2. **KOSHA MSDS**: 상업 이용 가능 여부(포털 "제한 없음"과 KOSHA 사이트 문구가 상충)
3. **K-MDS, KoMaP, matcenter, AI Hub 재료 물성, 환경 빅데이터 연계 데이터**: 라이선스, 다운로드 권한, 해외 반출 조건
4. **KRISS 국가참조표준**: DB 적재 이용협약 조건, 오픈 API로 물성 값 본문을 받을 수 있는지
5. **AMCSD, RRUFF**(IMA DB CSV 포함): 명시적 라이선스, rruff.net 이전 후 약관
6. **라이선스 문구가 없는 파일**: SGTE unary50, PSI/Nagra TDB 2020, NIST Solder TDB, 2DMatPedia, CIAAW 데이터 재사용 조건
7. **BGS**: OGL과 비상업 약관 중 무엇이 우선하는지. **IEA** Critical Minerals Dataset: 라이선스 원문(스니펫만 확인)
8. **Meta 모델 약관**: UMA, OMat24 모델 가중치의 상업 이용 범위(법무 검토). OMol25 HF 게이트 방식
9. **MPtrj**: figshare MIT 표기와 원천 MP(CC BY 4.0)의 관계
10. **THEREDA**: CC BY-ND에서 형식 변환본을 배포할 수 있는지. PHREEQC에 동봉된 Thermoddem 파일을 재배포할 수 있는지
11. **mendeleev와 pymatgen 수록 데이터**: 속성별 원출처와 권리. 특히 인용키가 없는 열전도, 융해·증발열, 격자상수
12. **MP 현행 약관**: next-gen 약관 페이지는 봇 403이라 legacy 약관(CC BY 4.0)으로만 확인했습니다.

### 규모·버전·가용성
13. **MP**: v2026.04.13 라이브 총 재료 수(API 키 필요), S3 280,159건과 라이브의 일치 여부, OPTIMADE 갱신 계획(2023년에 멈춤), 공개 S3에 GNoME 부분이 포함되는지
14. **OQMD**: v1.8(2026-02) 재확인(2026-09-26 서버 502), OPTIMADE·REST 502가 일시적인지

16. **JARVIS**: NIST OPTIMADE 장애, 2025-09 스냅샷(93,902)이 jarvis-tools에 반영되었는지, 데이터의 퍼블릭 도메인 여부 최종 판단

18. **MPDS**: 익명 OPTIMADE에서 오픈 서브셋까지 `commercial`로 표시되는 이유, 오픈 데이터 API 신청 절차
19. **COD**: CC0 전환 시점과 공지. **Mindat**: 광물·산지 수 원문(스니펫만), AI/ML 학습 제한 문구
